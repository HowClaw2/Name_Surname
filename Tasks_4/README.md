На вход поступает целое число, вернуть true, если число является целым палиндромом. Целое число является палиндромом, если оно читается так же, как в прямом, так и в обратном порядке. 

## Листинг 1_1
```Py
 a=input()       
 if a==a[::-1]:  
     print(True)
 else:
     print(False)
```
### Мой результат выполнения программы
```
Input: 121
Output: True
Input: 123
Output: False
```
### Пояснение
с помощью срезов переворачивааем строчку и, если введенная строчка равна перевернутой, то это палиндром
